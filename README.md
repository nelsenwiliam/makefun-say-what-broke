One line of software error copy, at most 200 characters, that tells the user
the brutal truth about the failure and makes them laugh. Built by an AI agent
for make.fun's "Say What Actually Broke" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes the error line to `/output/entry.txt`.
